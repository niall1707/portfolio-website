Final Year Project · TU Dublin · Submitted April 2026

Locker Logic

Final Year Project BSc CS Infrastructure · TU Dublin Submitted April 2026

Smart Locker System for Students with ADHD & Dyslexia

A full-stack IoT system that helps neurodivergent students stay organised by automatically tracking books in their locker against their timetable.

Supervisor: Denis Manly

Track

RFID-tagged books are scanned in and out as students access their locker. The Raspberry Pi 5 logs every scan to a local SQLite database in real time.

Sync

Events sync to a cloud PostgreSQL database on DigitalOcean. Offline-first design means the locker keeps working when school WiFi drops.

Remind

A background job compares locker contents against the student's timetable and surfaces reminders on the in-locker touchscreen and the web app.

3-Tier Architecture

Tier 1 — Edge

Raspberry Pi 5 · ACR122U NFC reader · Touchscreen · SQLite · systemd kiosk service

Tier 2 — Cloud

DigitalOcean droplet · Flask 3.0 · PostgreSQL · Flask-Login multi-role auth

Tier 3 — Client

Responsive web browser · Student, Teacher, and Admin dashboards

Tech Stack

Python Flask 3.0 PostgreSQL SQLite Raspberry Pi OS ACR122U NFC/RFID pyscard Flask-Login HTML / CSS / JS systemd

Deep Dives

Engineering Highlights

01

Offline-First Architecture

Dual database (local SQLite + cloud Postgres) means the locker keeps working when school WiFi drops. Validated by deliberately pulling the network mid-session.

02

USB Hard-Reset Workaround

The ACR122U has an undocumented USB state contention bug. A kernel-level reset on startup and on any runtime error fixed it — and accidentally provided double-scan prevention as a side effect.

03

Phantom Scan Prevention

Unknown RFID UIDs return 404 instead of creating spurious DB entries, with a 30s TTL alert feeding frontend toast notifications for immediate user feedback.

04

Multi-Role Authentication

A single login route routes students, teachers, and admins to separate dashboards with route-level access guards, implemented using Flask-Login.
